# North Madagascar Land-Cover Mapping Workflow

## Overview
This repository contains the complete workflow used to produce land-cover maps for northern Madagascar from multi-source Earth Observation data.

The workflow combines Sentinel-1, Sentinel-2, Google Satellite Embeddings, topographic, and rainfall information using the sits framework together with Google Earth Engine.

The first part of the workflow follows the methodology described in the official sits Book, providing a fully reproducible implementation of data cube generation, Random Forest and TempCNN classification.

The main methodological contribution of this repository is the integration of Google Satellite Embeddings into the sits ecosystem through a dedicated conversion pipeline, allowing embedding-based probability maps generated in Google Earth Engine to be seamlessly combined with SITS classifiers and ensemble models.

---

## Workflow overview

The workflow consists of six complementary scripts.

1. Build harmonized EO cubes (R / sits) : 1_CubeCreation.R
2. Train Random Forest and TempCNN classifiers (R / sits) : 2_MapCreation.R
3. Train a Google Satellite Embedding classifier (Google Earth Engine) : see the **Google Earth Engine implementation** section below
4. Convert GEE probability maps into SITS-compatible cubes (R) : 4_GEO_integretion.R
5. Build an ensemble classifier from the three probability cubes (R/sits) : 5_EnsembleModel.R
6. Statistically compare all classification maps using McNemar's test (R) : 6_Statistics.R
---

## 1. Cube Creation (1_CubeCreation.R)
Generates harmonized Earth Observation data cubes using the sits framework.
This script closely follows the methodology described in the official sits Book.

The script:

- downloads Sentinel-1, Sentinel-2, DEM and CHIRPS rainfall data
- regularizes all datasets and harmonizes them to a common 10 m spatial grid
- computes spectral indices (NDVI, EVI, SIPI, GNDVI, NDMI and BSI)

The resulting cubes are used throughout the remainder of the workflow.

---

## 2. Model Training (2_ModelTraining.R)
Trains the Random Forest and TempCNN classifiers and produces probability cubes.

Main steps include:

- Extraction of training samples
- Training sample quality assessment and cleaning
- Random Forest model training
- Generation of Random Forest probability cubes
- TempCNN hyperparameter optimization
- TempCNN model training
- Generation of TempCNN probability cubes
- Bayesian spatial smoothing
- Production of final thematic maps

---

## 3. Google Earth Engine Classification

Implements the Google Earth Engine workflow based on Google's Satellite Embeddings.

The script:

- builds multi-year embedding stacks
- trains a Random Forest classifier
- generates class probability maps
- exports probability cubes by Sentinel-2 tile

---

## 4. Google Earth Engine to SITS (4_GEE_to_SITS.R)

**This script constitutes the main methodological contribution of this repository.**
Converts probability maps exported from Google Earth Engine into SITS-compatible probability cubes.

Main steps:

- mosaic exported tiles
- align rasters to the Sentinel-2 reference grid
- reorder probability layers
- calibrate probabilities
- export optimized GeoTIFF files

The resulting probability cubes can be directly used by the sits framework.

---

## 5. Ensemble Model (5_EnsembleModel.R)

Builds the final ensemble classification by combining the probability cubes generated by the three independent classifiers:

- Random Forest
- TempCNN
- Google Satellite Embeddings

The script generates the final ensemble probability cube and the corresponding land-cover map.

---

## 6. Statistical Comparison (6_Statistics.R)
Statistically compares all generated land-cover maps.

The script:

- extracts predicted classes at validation points
- performs pairwise McNemar tests
- applies Holm correction for multiple comparisons
- exports the statistical comparison tables

## Reference

Most of the R workflow is based on the sits package and follows the methodology described in the official documentation:

https://e-sensing.github.io/sitsbook/

While Scripts 1 and 2 reproduce established SITS workflows, Scripts 3–5 extend the framework by integrating Google Satellite Embeddings into the SITS ecosystem and combining them within an ensemble classification workflow.
